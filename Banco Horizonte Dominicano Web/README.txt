BANCO HORIZONTE DOMINICANO — PROYECTO ACADÉMICO
================================================

Descripción
-----------
Sitio web demostrativo de un banco ficticio, creado desde cero como referencia
de arquitectura de sitios bancarios. No es una copia de Banreservas ni de otra
entidad real. No ofrece servicios financieros y no está conectado a un banco.

Archivos
--------
index.html       Estructura y contenido del sitio.
css/styles.css   Diseño visual, menú adaptable y estilos responsive.
js/main.js       Menú móvil, navegación activa, consejos, formulario demostrativo
                 y botón para volver arriba.

Cómo abrirlo en Visual Studio Code
----------------------------------
1. Extrae la carpeta Banco_Horizonte_Web.zip.
2. Abre Visual Studio Code.
3. Selecciona Archivo > Abrir carpeta y elige Banco_Horizonte_Web.
4. Abre index.html en el navegador. Puedes usar la extensión Live Server para
   previsualizar cambios automáticamente, aunque no es obligatoria.
5. Para editar el diseño, modifica css/styles.css. Para cambiar el texto, edita
   index.html. Para ajustar interacciones, edita js/main.js.

Publicación
-----------
Para entregar una URL pública, tendrás que publicar los archivos en un servicio
de alojamiento estático (por ejemplo, GitHub Pages o Netlify). La URL no se
puede crear únicamente desde tu computadora; sigue el proceso de publicación
de la plataforma elegida y sube la carpeta del proyecto.

Notas
-----
- El formulario solo muestra un mensaje de demostración y no envía datos.
- Los saldos y datos que aparecen en la ilustración móvil son ficticios.
- No incluyas información personal, contraseñas ni datos bancarios reales.
- Para el proyecto se usa una fuente externa de Google Fonts; el sitio también
  mantiene una estructura legible si esa fuente no está disponible.
