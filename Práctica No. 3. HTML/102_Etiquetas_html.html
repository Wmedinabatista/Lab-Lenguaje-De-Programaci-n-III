102 Etiquetas HTML

Guía de referencia con numeración, descripción, ejemplo de uso y elementos adicionales.

¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje de marcado que estructura el contenido de las páginas web. Sus etiquetas identifican elementos como encabezados, párrafos, enlaces, imágenes, formularios y tablas.

Esta guía presenta 102 etiquetas HTML diferentes. Los ejemplos son ilustrativos: los archivos de imagen, audio, video y otros recursos deben existir para que puedan mostrarse o reproducirse.

1 <a> Define un hipervínculo hacia otra página, archivo o ubicación. 
<a href="https://example.com">Visitar Example</a>
 El atributo href indica el destino; target="_blank" abre otra pestaña.
2 <abbr> Representa una abreviatura o acrónimo. 
<abbr title="HyperText Markup Language">HTML</abbr>
 title puede mostrar el significado completo al pasar el cursor.
3 <address> Proporciona información de contacto relacionada con una página o artículo. 
<address>Contacto: info@example.com</address>
 No se debe usar solo para poner cualquier texto en cursiva.
4 <area> Define una zona interactiva dentro de un mapa de imagen. 
<area shape="rect" coords="0,0,100,50" href="inicio.html" alt="Inicio">
 Se utiliza dentro de <map> y necesita un texto alternativo útil.
5 <article> Representa contenido independiente, como una noticia o publicación. 
<article><h2>Noticia</h2><p>Contenido...</p></article>
 Puede tener sentido por sí mismo fuera del contexto de la página.
6 <aside> Representa contenido complementario al contenido principal. 
<aside><p>Lecturas relacionadas</p></aside>
 Suele utilizarse para barras laterales o notas relacionadas.
7 <audio> Inserta contenido de audio. 
<audio controls src="audio.mp3">Tu navegador no admite audio.</audio>
 controls muestra los controles de reproducción.
8 <b> Llama la atención sobre texto sin añadir importancia semántica. 
<p>Oferta: <b>50 % de descuento</b></p>
 Para importancia semántica, normalmente se prefiere <strong>.
9 <blockquote> Representa una cita extensa procedente de otra fuente. 
<blockquote cite="https://example.com">Una cita extensa.</blockquote>
 cite puede indicar la fuente de la cita.
10 <body> Contiene el contenido visible del documento HTML. 
<body><h1>Hola</h1><p>Bienvenido</p></body>
 En un documento normal hay un solo elemento body.
11 <br> Inserta un salto de línea. 
Primera línea<br>Segunda línea
 Es un elemento vacío; no necesita etiqueta de cierre.
12 <button> Crea un botón interactivo. 
<button type="button">Presionar</button>
 Dentro de un formulario, especifica type para evitar envíos accidentales.
13 <canvas> Proporciona un área de dibujo controlable mediante JavaScript. 
<canvas id="lienzo" width="200" height="100">Dibujo</canvas>
 Conviene incluir contenido alternativo dentro del elemento.
14 <caption> Añade un título descriptivo a una tabla. 
<table><caption>Notas del curso</caption></table>
 Debe ser el primer elemento hijo de table.
15 <cite> Marca el título de una obra creativa. 
<p>Leí <cite>Don Quijote de la Mancha</cite>.</p>
 No está pensado para marcar el nombre de una persona.
16 <code> Representa un fragmento de código informático. 
<code>console.log("Hola")</code>
 Para conservar espacios y saltos de línea, puede combinarse con <pre>.
17 <datalist> Ofrece sugerencias para un campo de entrada. 
<input list="colores"><datalist id="colores"><option value="Azul"></datalist>
 Se vincula mediante el atributo list del input.
18 <dd> Describe o define un término o nombre dentro de una lista de descripción. 
<dl><dt>HTML</dt><dd>Lenguaje de marcado.</dd></dl>
 Normalmente aparece dentro de dl, después de dt.
19 <del> Indica texto eliminado de un documento. 
<p>Precio: <del>100</del> 80</p>
 datetime puede indicar cuándo se realizó el cambio.
20 <details> Crea un control desplegable que el usuario puede abrir o cerrar. 
<details><summary>Ver más</summary><p>Información adicional.</p></details>
 summary proporciona el encabezado visible del control.
21 <dfn> Marca el término que se está definiendo. 
<p><dfn>HTML</dfn> es un lenguaje de marcado.</p>
 La definición suele aparecer en el contexto cercano.
22 <dialog> Representa un cuadro de diálogo o ventana interactiva. 
<dialog open>Mensaje de ejemplo</dialog>
 JavaScript puede abrirlo y cerrarlo con sus métodos.
23 <div> Agrupa contenido en un contenedor genérico sin significado semántico propio. 
<div class="tarjeta">Contenido</div>
 Se usa con CSS para organizar el diseño.
24 <dl> Representa una lista de pares término-descripción. 
<dl><dt>CPU</dt><dd>Procesador del equipo.</dd></dl>
 Sus elementos habituales son dt y dd.
25 <dt> Identifica un término o nombre en una lista de descripción. 
<dl><dt>CSS</dt><dd>Estilos de una página.</dd></dl>
 Se utiliza dentro de dl.
26 <em> Marca texto con énfasis. 
<p>Debes <em>leer</em> las instrucciones.</p>
 Los lectores de pantalla pueden expresar el énfasis.
27 <fieldset> Agrupa controles relacionados dentro de un formulario. 
<fieldset><legend>Datos personales</legend><input name="nombre"></fieldset>
 legend proporciona el título del grupo.
28 <figcaption> Proporciona una leyenda o descripción para una figura. 
<figure><img src="foto.jpg" alt="Paisaje"><figcaption>Paisaje al atardecer</figcaption></figure>
 Se coloca dentro de figure.
29 <figure> Agrupa contenido autónomo, como una imagen, diagrama o ejemplo. 
<figure><img src="foto.jpg" alt="Paisaje"><figcaption>Paisaje</figcaption></figure>
 Puede incluir una leyenda mediante figcaption.
30 <footer> Representa el pie de una página o de una sección. 
<footer><p>© 2026 Mi sitio</p></footer>
 Puede contener autoría, enlaces o información relacionada.
31 <form> Agrupa controles para enviar información del usuario. 
<form action="/registro" method="post"><input name="nombre"><button>Enviar</button></form>
 action define el destino y method el método de envío.
32 <h1> Representa un encabezado de nivel 1, normalmente el título principal. 
<h1>Mi página web</h1>
 Organiza jerárquicamente el contenido; usa niveles en orden lógico.
33 <h2> Representa un encabezado de nivel 2. 
<h2>Sección principal</h2>
 Suele dividir el contenido bajo un h1.
34 <h3> Representa un encabezado de nivel 3. 
<h3>Subsección</h3>
 Debe reflejar la estructura jerárquica del documento.
35 <h4> Representa un encabezado de nivel 4. 
<h4>Detalle de la subsección</h4>
 No se elige solo por el tamaño visual; el tamaño se controla con CSS.
36 <h5> Representa un encabezado de nivel 5. 
<h5>Subapartado</h5>
 Úsalo cuando la estructura semántica requiera este nivel.
37 <h6> Representa un encabezado de nivel 6. 
<h6>Detalle final</h6>
 Es el nivel de encabezado menos alto.
38 <head> Contiene metadatos y referencias a recursos del documento. 
<head><title>Mi página</title><meta charset="UTF-8"></head>
 Su contenido normalmente no se muestra como contenido de página.
39 <header> Representa contenido introductorio o un conjunto de elementos de navegación. 
<header><h1>Mi sitio</h1></header>
 Puede aparecer al inicio de la página o de una sección.
40 <hr> Representa una separación temática entre contenidos. 
<p>Primera idea</p><hr><p>Nueva idea</p>
 Visualmente suele mostrarse como una línea horizontal.
41 <html> Es el elemento raíz que contiene todo el documento HTML. 
<!DOCTYPE html><html lang="es">...</html>
 El atributo lang ayuda a tecnologías de asistencia y buscadores.
42 <i> Representa texto en una voz o estado alternativo, como un término técnico. 
<p>El término <i>in situ</i> es común.</p>
 No debe utilizarse únicamente para cursiva decorativa.
43 <iframe> Inserta otra página web dentro de la página actual. 
<iframe src="https://example.com" title="Página de ejemplo"></iframe>
 Incluye title descriptivo y considera la seguridad del contenido incrustado.
44 <img> Incrusta una imagen. 
<img src="imagen.jpg" alt="Un paisaje">
 El atributo alt describe la imagen para accesibilidad.
45 <input> Crea un control de entrada de formulario. 
<input type="email" name="correo" required>
 type define el tipo de control; label mejora su accesibilidad.
46 <ins> Indica texto insertado en una versión del documento. 
<p>El resultado es <ins>correcto</ins>.</p>
 datetime puede registrar la fecha de inserción.
47 <kbd> Representa una entrada que el usuario debe realizar mediante teclado. 
<p>Presiona <kbd>Ctrl</kbd> + <kbd>S</kbd>.</p>
 Se usa para teclas o combinaciones de teclas.
48 <label> Asocia un texto descriptivo con un control de formulario. 
<label for="correo">Correo</label><input id="correo" type="email">
 El valor de for debe coincidir con el id del control.
49 <legend> Proporciona un título para un grupo fieldset. 
<fieldset><legend>Preferencias</legend><input type="checkbox"></fieldset>
 Mejora la comprensión de grupos de controles.
50 <li> Representa un elemento de una lista. 
<ul><li>Manzana</li><li>Pera</li></ul>
 Se usa normalmente dentro de ul, ol o menu.
51 <link> Relaciona el documento con un recurso externo, como una hoja de estilos. 
<link rel="stylesheet" href="estilos.css">
 Se coloca normalmente en head.
52 <main> Identifica el contenido principal y único de la página. 
<main><h1>Contenido principal</h1></main>
 Generalmente debe haber un solo main visible por documento.
53 <mark> Resalta texto relevante en el contexto actual. 
<p>Busca la palabra <mark>HTML</mark>.</p>
 El resaltado predeterminado suele ser amarillo, pero puede cambiarse con CSS.
54 <menu> Representa una lista de elementos o comandos. 
<menu><li><button>Guardar</button></li></menu>
 Su presentación puede personalizarse con CSS.
55 <meta> Define metadatos del documento, como codificación o configuración móvil. 
<meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1.0">
 Se coloca dentro de head.
56 <meter> Representa una medida dentro de un rango conocido. 
<label>Uso de disco: <meter min="0" max="100" value="65">65%</meter></label>
 No es apropiado para indicar el progreso de una tarea; para eso existe progress.
57 <nav> Agrupa enlaces de navegación importantes. 
<nav><a href="index.html">Inicio</a><a href="contacto.html">Contacto</a></nav>
 No todos los grupos de enlaces necesitan nav.
58 <noscript> Proporciona contenido alternativo cuando JavaScript no está disponible o está desactivado. 
<noscript>Activa JavaScript para usar esta función.</noscript>
 El contenido se muestra según el soporte de scripts del navegador.
59 <object> Inserta un recurso externo, como un documento o contenido multimedia. 
<object data="documento.pdf" type="application/pdf">No se pudo mostrar el PDF.</object>
 Incluye contenido alternativo para casos no compatibles.
60 <ol> Crea una lista ordenada, normalmente numerada. 
<ol><li>Primero</li><li>Segundo</li></ol>
 Puede usar atributos start, reversed y type.
61 <optgroup> Agrupa opciones relacionadas dentro de un menú select. 
<select><optgroup label="Frutas"><option>Manzana</option></optgroup></select>
 El atributo label identifica el grupo.
62 <option> Define una opción dentro de select o datalist. 
<select><option value="rd">República Dominicana</option></select>
 value es el dato enviado cuando se selecciona la opción.
63 <output> Muestra el resultado de un cálculo o acción del usuario. 
<output name="resultado">15</output>
 Puede vincularse a controles mediante atributos como for.
64 <p> Representa un párrafo de texto. 
<p>Este es un párrafo.</p>
 Los navegadores suelen separar los párrafos con margen.
65 <picture> Permite ofrecer distintas fuentes de imagen según condiciones. 
<picture><source media="(min-width: 800px)" srcset="grande.jpg"><img src="pequena.jpg" alt="Paisaje"></picture>
 Incluye un img como alternativa obligatoria dentro de picture.
66 <pre> Representa texto preformateado que conserva espacios y saltos de línea. 
<pre>línea 1
línea 2</pre>
 Es útil para código y texto donde importan los espacios.
67 <progress> Muestra el avance de una tarea. 
<progress value="70" max="100">70%</progress>
 Si se omite value, el progreso es indeterminado.
68 <q> Marca una cita breve dentro de una línea de texto. 
<p>Ella dijo: <q>Hola a todos</q>.</p>
 Los navegadores suelen añadir comillas automáticamente.
69 <rp> Proporciona paréntesis alternativos para navegadores que no admiten anotaciones ruby. 
<ruby>漢 <rp>(</rp><rt>kan</rt><rp>)</rp></ruby>
 Se utiliza junto con ruby y rt.
70 <rt> Contiene la anotación o pronunciación de caracteres en una estructura ruby. 
<ruby>漢<rt>kan</rt></ruby>
 Es útil para anotaciones fonéticas, especialmente en idiomas asiáticos.
71 <ruby> Representa anotaciones ruby, como guías de pronunciación. 
<ruby>漢<rt>kan</rt></ruby>
 Normalmente contiene texto base y rt.
72 <s> Indica texto que ya no es exacto o relevante, sin representar una eliminación editorial. 
<p><s>Precio anterior: 100</s> Precio actual: 80</p>
 Para una modificación editorial, considera del o ins.
73 <samp> Representa una salida de ejemplo de un programa o sistema. 
<p>Resultado: <samp>Archivo guardado</samp></p>
 Se usa para salida de computadora, no para código fuente.
74 <script> Incluye o enlaza código ejecutable, normalmente JavaScript. 
<script src="app.js" defer></script>
 Usa defer o type="module" cuando corresponda.
75 <search> Representa una sección destinada a funciones de búsqueda o filtrado. 
<search><form><input type="search" placeholder="Buscar"><button>Buscar</button></form></search>
 Ayuda a identificar semánticamente el área de búsqueda.
76 <section> Representa una sección temática de contenido, normalmente con encabezado. 
<section><h2>Servicios</h2><p>Descripción...</p></section>
 No es solo un contenedor de estilo; para eso puede usarse div.
77 <select> Crea un menú desplegable de opciones. 
<select name="pais"><option>República Dominicana</option></select>
 Puede incluir option y optgroup.
78 <small> Representa comentarios secundarios o letra pequeña. 
<p><small>Aplican condiciones.</small></p>
 No debe usarse solo para reducir el tamaño visual.
79 <source> Especifica una fuente alternativa para picture, audio o video. 
<video controls><source src="video.mp4" type="video/mp4"></video>
 Debe colocarse dentro del elemento multimedia correspondiente.
80 <span> Agrupa texto en línea sin añadir significado semántico propio. 
<p>Estado: <span class="activo">Activo</span></p>
 Es útil para aplicar estilos o manipular contenido con JavaScript.
81 <strong> Indica que un texto tiene gran importancia, seriedad o urgencia. 
<p><strong>Atención:</strong> guarda los cambios.</p>
 Suele mostrarse en negrita, pero su valor principal es semántico.
82 <style> Incluye reglas CSS dentro del documento. 
<style>p { color: navy; }</style>
 Suele colocarse en head, aunque existen otros contextos permitidos.
83 <sub> Representa texto en subíndice. 
<p>H<sub>2</sub>O</p>
 Se utiliza en fórmulas químicas y notación.
84 <summary> Proporciona el rótulo visible de un elemento details. 
<details><summary>Información</summary><p>Contenido desplegable.</p></details>
 Debe ser el primer hijo de details.
85 <sup> Representa texto en superíndice. 
<p>2<sup>3</sup> = 8</p>
 Se usa en exponentes y notas de referencia.
86 <table> Representa datos organizados en filas y columnas. 
<table><tr><th>Nombre</th><td>Ana</td></tr></table>
 Usa encabezados th y, cuando convenga, thead, tbody y tfoot.
87 <tbody> Agrupa las filas principales del cuerpo de una tabla. 
<table><tbody><tr><td>Dato</td></tr></tbody></table>
 Permite separar el cuerpo de los encabezados y pies.
88 <td> Representa una celda de datos de una tabla. 
<tr><td>Wilmy</td><td>90</td></tr>
 Puede combinar celdas con colspan o rowspan.
89 <template> Contiene HTML que no se muestra hasta que se utiliza mediante código. 
<template id="tarjeta"><p>Tarjeta nueva</p></template>
 JavaScript puede clonar su contenido para reutilizarlo.
90 <textarea> Crea un campo de texto multilínea. 
<textarea name="comentario" rows="4" cols="30"></textarea>
 Para asociarlo a un formulario, usa label.
91 <tfoot> Agrupa las filas de resumen o pie de una tabla. 
<table><tfoot><tr><td>Total: 100</td></tr></tfoot></table>
 Es útil para totales o resúmenes.
92 <th> Representa una celda que funciona como encabezado de tabla. 
<tr><th scope="col">Nombre</th></tr>
 scope ayuda a relacionar el encabezado con las celdas.
93 <thead> Agrupa las filas de encabezado de una tabla. 
<table><thead><tr><th>Nombre</th></tr></thead></table>
 Mejora la organización semántica de tablas extensas.
94 <time> Representa una fecha u hora legible por máquina. 
<time datetime="2026-10-20">20 de octubre de 2026</time>
 datetime permite especificar un valor normalizado.
95 <title> Define el título del documento que suele aparecer en la pestaña del navegador. 
<title>Mi página web</title>
 Se coloca dentro de head y es importante para accesibilidad y buscadores.
96 <tr> Representa una fila de una tabla. 
<tr><td>Ana</td><td>95</td></tr>
 Dentro de la fila se colocan celdas th o td.
97 <track> Añade pistas de texto temporizadas a audio o video, como subtítulos. 
<video controls><track src="subtitulos.vtt" kind="subtitles" srclang="es" label="Español"></video>
 Permite ofrecer subtítulos y otras pistas accesibles.
98 <u> Marca texto con una anotación no textual, como un nombre propio mal escrito o un término anotado. 
<p>Palabra <u>anotada</u>.</p>
 No debe usarse solo para subrayar; los usuarios pueden confundirlo con un enlace.
99 <ul> Crea una lista sin orden numérico. 
<ul><li>Pan</li><li>Leche</li></ul>
 Cada elemento de la lista se representa con li.
100 <var> Representa una variable en una expresión matemática o de programación. 
<p>El área es <var>base</var> × <var>altura</var>.</p>
 Suele mostrarse en cursiva por defecto.
101 <video> Inserta contenido de video. 
<video controls width="320"><source src="video.mp4" type="video/mp4">Tu navegador no admite video.</video>
 controls permite reproducir; ofrece subtítulos con track.
102 <wbr> Indica un lugar donde el navegador puede insertar un salto de línea si hace falta. 
<p>supercalifragilístico<wbr>expialidoso</p>
 No fuerza un salto; solo marca una oportunidad.
